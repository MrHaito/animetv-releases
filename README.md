# AnimeTV

Личная тестовая сборка приложения для Android TV.

[Скачать актуальный APK](https://github.com/MrHaito/animetv-releases/releases/latest/download/AnimeTV-universal.apk)

## Установка и обновления

Нужен Android 8.0 или новее. Универсальный APK содержит armeabi-v7a,
arm64-v8a и x86_64, в том числе для старых Mi Box с 32-битной системой.

Первую версию установи вручную. Последующие версии доступны через кнопку
«Проверить обновления» в приложении. С версии 0.6.0 она находится в Настройках. Android попросит разрешить установку
из этого источника и подтвердить обновление. Удалять приложение не нужно.

APK подписан постоянным ключом выпуска. Учетные записи и прогресс
сохраняются при установке обновлений поверх этой же release-сборки.
Локальные debug-сборки имеют другую подпись и отдельный цикл тестирования.

## Текущее состояние

- Версия 0.6.0: меню слева, библиотека с постерами и общими карточками сериалов.
- Списки Смотрю и Запланировано, счетчики серий из Shikimori.
- Поиск по Shikimori, объединение основной линии сезонов, выбранные части в планы.
- Хронология по возрастанию дат и связанные произведения.
- Видео и исходные ASS-субтитры Anime365 через Media3 и libass.
- Позиция просмотра, перевод, аудиодорожка и переход к следующей серии.
- Порог просмотренной серии 85%, отправка отметок в Shikimori.
- Проверка обновлений через публичные GitHub Releases.

Аккаунты подключаются отдельно. В APK нет токенов Anime365, OAuth-токенов,
client_secret Shikimori и персональной истории просмотра.
С версии 0.5.1 аккаунты можно подключать с ПК через временный зашифрованный
канал в локальной сети: на ТВ кнопка «Подключить аккаунты с ПК», на компьютере
локальный помощник проекта connect-tv.ps1. На ТВ вводить токены не нужно.
Помощнику нужны собственные локальные настройки сервисов. ADB не требуется.
На физическом Mi Box с Android 9 пользователь подтвердил подключение
обоих сервисов, просмотр с позиционированными субтитрами, появление отметки
Shikimori и обновление 0.5.2 -> 0.5.3 через приложение.
В 0.5.3 исправлен запрос сертификатов APK для Android 9.
Новый интерфейс 0.6.0 проверен в эмуляторе Android TV API 36,
на физической приставке его еще предстоит проверить.
Связанные фильмы и книги пока открываются на сайте Shikimori.
